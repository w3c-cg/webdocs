#### Towards a Docs CG playbook

- Discussed how to find out which documentation projects are needed, how to scope them, and how to prioritize them. The need for a "Docs CG playbook": how we find, scope, plan, and execute projects.

- Discussed Documentation archetypes: https://github.com/google/opendocs/tree/main/project_archetypes: docs activities. Not all are very applicable to docs CG but several could be useful input to a docs playbook (including, especially, Study/Audit/Manual).

- We talked a lot about the study, the audit, and the manual.

- Discussed the security docs project, what worked and what didn't.

- The security part is finished, the Privacy part is not yet finished. We want to do a retrospective here to see what worked and what didnt. Also, we want to take things from here and put it in a draft "playbook"
